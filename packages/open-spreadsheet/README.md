# open-spreadsheet

An Excel-like spreadsheet for coding agents and people. This package is the
short name for the CLI in [`@open-spreadsheet/core`](https://www.npmjs.com/package/@open-spreadsheet/core):

```bash
npx open-spreadsheet init my-sheets
cd my-sheets && npm install && npx open-spreadsheet dev
```

Everything else — the editor, the formula engine, the MCP server
(`open-spreadsheet-mcp`) — is in `@open-spreadsheet/core`. See the
[repository](https://github.com/simonliu-ai-product/open-spreadsheet) for the full guide.
